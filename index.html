EcoGuard — Forest Threat Sound Detection

An audio-based forest monitoring system that detects potential threats such as chainsaws, gunshots, and fire by comparing classical machine learning models with a deep learning approach.

View on GitHub

Project Workflow

  1. Combine audio from eight source datasets
  2. Clean and standardize audio to mono, 16 kHz, and 3 seconds
  3. Extract MFCC and spectral features or log-mel spectrograms
  4. Train and compare six classical models with a CRNN model
  5. Evaluate results and display predictions and alerts in Streamlit

PROJECT 05 / 08

Medical Image Registration Using PSO

An image registration application that aligns two images by optimizing rotation, translation, and scale with Particle Swarm Optimization (PSO), with visual comparisons and alignment metrics.

View on GitHub

Project Workflow

  1. Load the images and standardize their dimensions
  2. Apply geometric transformations to create registration test cases
  3. Represent each particle with rotation, horizontal and vertical translation, and scale parameters
  4. Optimize the transformation with PSO and multiple similarity metrics
  5. Display the registered image, difference map, convergence curve, and a PDF report
