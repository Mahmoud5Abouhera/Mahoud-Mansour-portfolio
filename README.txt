Folder structure:
- index.html
- assets/profile.jpg                 <- replace this with your own photo, keeping the name profile.jpg
- assets/projects/                   <- project screenshot images
- assets/certificates/               <- certificate images
- README.txt

To replace your photo:
1. Put your real photo at assets/profile.jpg (overwrite the placeholder).
2. Keep the filename exactly profile.jpg.

To replace project screenshots:
- Replace the SVG placeholders in assets/projects/ with your real images.
- If you use JPG/PNG instead of SVG, update the matching src paths in index.html.

To replace certificate images:
- Replace the placeholders in assets/certificates/ with your real certificate images.

  Machine Learning (IBM), Artificial Intelligence Fundamentals (IBM SkillsBuild), and
  Data Science & Machine Learning (Edraak).

Personal links:
- Search index.html for YOUR-GITHUB-USERNAME and YOUR-LINKEDIN-USERNAME and replace them with your actual links.

GitHub Pages:
1. Upload index.html and the complete assets folder to the repository root.
2. Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save.
